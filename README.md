# Hero Vired Data Science & Machine Learning Assignments

This repository contains all assignments and projects completed as part of the Hero Vired program in Data Science, Artificial Intelligence, and Machine Learning.

## Repository Structure

- **`Dataset/`**: Contains the raw and cleaned datasets used across different assignments (transactions, loans, customers, etc.).
- **`EDA ASSIGNMENTS/`**: Contains Exploratory Data Analysis (EDA) Jupyter notebooks and reports (e.g., `KUMKUM_GUPTA_BATCH03.ipynb`).
- **`python assignment/`**: Contains fundamental Python programming assignments and final HTML reports.
- **`Statstics Assignment/`**: Contains statistics-focused Jupyter notebooks.
