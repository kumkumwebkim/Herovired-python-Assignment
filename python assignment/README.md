# Hero FinCorp - Loan Portfolio Analysis

## Project Overview
This project involves a comprehensive exploratory data analysis (EDA) and statistical modeling of Hero FinCorp's loan portfolio. The primary objective is to evaluate customer behavior, identify default risks, assess branch efficiency, and improve overall profitability through data-driven insights.

## Tasks Covered
The analysis covers 20 critical tasks including:
1. **Data Quality and Preparation**: Cleaning, handling missing values, and standardizing datasets (Applications, Branches, Customers, Defaults, Loans, Transactions).
2. **Customer Segmentation**: Analyzing demographics and loan preferences.
3. **Branch Performance**: Evaluating loan disbursement and delinquency rates across different regions.
4. **Default Risk Analysis**: Identifying key factors leading to loan defaults and calculating recovery rates.
5. **Trend Analysis**: Visualizing disbursement trends and seasonal patterns.
6. **Financial Reporting**: Generating automated insights and exporting results.

## Technologies Used
- **Language**: Python 3.x
- **Libraries**:
  - `Pandas`: Data manipulation and analysis.
  - `NumPy`: Numerical operations.
  - `Matplotlib` & `Seaborn`: Data visualization and insights.
  - `OS`: File and directory management.

## Files in the Repository
- `python Assignment cover all task 1-20.ipynb`: Comprehensive notebook containing all 20 analysis tasks with detailed commentary and visualizations.
- `Hero_Fincorp by own.ipynb`: Supplementary analysis and custom explorations of the loan portfolio.
- `Final_Assignment_Report.html`: A professional, formatted report exported from the analysis.
- `Dataset/`: Directory containing the raw datasets used for the project.
